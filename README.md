# Joe Metri Desh

A playable browser-based 2D platformer inspired by rhythm platformers. Guide the glowing cube across the course, avoid spikes, and pass through portals to change movement modes.

## Play

Open [`index.html`](./index.html) in a browser, or enable GitHub Pages for the repository.

- **Cube:** press Space, Up Arrow, mouse, or touch to jump.
- **Ship:** hold to fly up; release to glide down smoothly.
- **Ball:** press to flip gravity smoothly.
- **Wave:** hold to move sharply up; release to move sharply down.
- **UFO:** press to flap upward like a flappy bird.
- Touching a spike ends the run. Reach the finish line to win.

The best distance is saved locally in your browser.
